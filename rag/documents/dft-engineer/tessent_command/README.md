# tessent_command (Tessent命令统一指导)

## 目录说明

- `scan_commands/` - Scan链插入相关命令
- `mbist_commands/` - MBIST存储器测试相关命令
- `atpg_commands/` - ATPG向量生成相关命令
- `flow_scripts/` - DFT流程自动化脚本

## 工具说明

**Tessent** 是 Synopsys 的 DFT (Design For Test) 解决方案，优先用于：

- **Scan Insertion**: Scan链插入与连接
- **MBIST**: 存储器内建自测试
- **ATPG**: 自动测试向量生成
